# Rastgele Felsefi Soru Üreticisi

Bu proje, insan zihnini tamamen gereksiz yere meşgul etmek için tasarlanmış üstün bir yazılımdır.

Her çalıştırdığınızda, varoluşunuzun anlamını sorgulamanıza neden olacak bir soru üretir. Sonra da o sorunun cevabını vermez. Çünkü cevap yoktur. Ya da vardır ama biz bilmiyoruz.

## Kullanım

```bash
python soru_uret.py
```

Çıkan soruyu düşünün. Çok düşünün. Sonra tekrar çalıştırın.

## Felsefi Gerekçe

Eğer bir soru cevaplanamıyorsa, belki de sorulmamalıydı. Ama biz yine de sorduk.
